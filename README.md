# CMSC 100 - Exercise 04

## JavaScript Basics Part 2

### Description

This project simulates a simple account validation program using JavaScript.

### Features

- Generates a unique ID using UUID
- Validates account information
- Validates email addresses
- Checks if the user is at least 18 years old
- Saves valid account information to `users.txt`

### Files

- `index.js` - Contains the main functions for generating unique IDs and adding accounts.
- `test.js` - Tests the functions in `index.js`.
- `package.json` - Contains the project information and dependencies.
- `package-lock.json` - Records the installed package versions.
- `.gitignore` - Prevents `node_modules` from being uploaded to GitHub.

### How to Run

1. Open the project folder in VS Code.
2. Open the terminal.
3. Run:

```bash
node test.js
